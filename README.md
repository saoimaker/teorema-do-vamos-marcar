# Teorema do Vamos Marcar
Paródia de painel de BI: estudo bayesiano (fictício) sobre "vamos marcar". Só o Bayes é real (`src/lib/bayes.ts`).
Stack: React + Vite + TypeScript + Tailwind + Recharts + Framer Motion. Sem backend.

    npm install && npm run dev

Supabase: não utilizado. Compartilha o projeto com outros sites, então nada aqui cria, altera ou apaga tabelas.
Se um dia precisar, use tabelas com prefixo próprio (ex.: `vm_`) e `create table if not exists`.
